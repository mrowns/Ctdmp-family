## Limits

The text-scale check uses a browser CSS override to simulate enlarged default text; it is not a screen-reader test or a complete WCAG audit. Network emulation is a deterministic local browser test, not a real mobile carrier test. It does not cover physical devices, every route, or all offline behavior. No real video or external provider request was made.
